Growth IA Ops

Política de privacidade

Vigente desde 28 de outubro de 2026.

Quem usa

Growth IA Ops é uma ferramenta interna, usada só pelo seu responsável. Ela não é oferecida ao público e não coleta dados de visitantes deste site.

Que dados do Google ela acessa

Com a autorização do próprio usuário (escopo https://www.googleapis.com/auth/adwords), a ferramenta acessa pela Google Ads API os dados das contas de anúncio a que esse usuário já tem acesso: contas, campanhas, grupos de anúncios, palavras-chave, termos de pesquisa, anúncios, conversões e métricas de desempenho. Ela não acessa e-mail, contatos, arquivos ou outros dados da conta Google.

Como os dados são usados

Os dados servem só para analisar e operar as contas de anúncio em nome do usuário. A ferramenta é operada por um assistente de IA (Claude, da Anthropic) na sessão do próprio usuário, que processa os dados para executar as tarefas que ele pede. Toda alteração numa conta de anúncio é simulada antes e só é aplicada com a confirmação explícita do usuário.

Onde ficam guardados

O token de autorização fica guardado no computador do usuário. Os dados lidos são processados nesse computador e nos registros privados do próprio usuário. A ferramenta não tem servidor próprio que receba os dados.

Compartilhamento

Os dados não são vendidos, não são compartilhados com terceiros para fins próprios deles e não são usados para publicidade.

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. A revogação invalida o token guardado.

Contato

Pelo e-mail de suporte exibido na tela de consentimento do Google, no momento da autorização.
